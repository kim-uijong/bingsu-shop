# 빙수 일러스트 자산 (52개)

각 빙수 폴더에 아래 4개 PNG 파일이 필요해요.

```
patbingsu/
  empty.png      ← 빈 그릇 (기대 표정)
  ice.png        ← 얼음 가득 (설레는 표정)
  topping.png    ← 토핑 올라가는 중 (행복한 표정)
  complete.png   ← 완성! 빛나는 빙수 (환호)
```

**13종 × 4상태 = 52개 PNG**

## 작업 방법

`docs/ILLUSTRATION_PROMPTS.md`의 프롬프트 시트를 그대로 ChatGPT Plus에 복붙하세요.

## 파일 사양

- **포맷**: PNG (투명 또는 흰 배경)
- **크기**: 1024×1024 권장 (정사각형 1:1)
- **파일명**: 영문 소문자 정확히 (`empty.png`, `ice.png`, `topping.png`, `complete.png`)
