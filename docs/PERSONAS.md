# QA 시나리오 (페르소나별 사용 흐름)

각 시나리오에서 잠재 이슈를 ⚠️로 표기.

## 시나리오 A — 박영자 (62세) 첫 진입

1. 토스 → 혜택탭 → "오늘의 빙수 가게" 진입
2. IntroModal 등장 → "처음 오셨네요" 인사 → 닫기
3. 메인 화면: 출석 선물 카드 + 빙수 만들기 버튼
4. **출석 선물** 카드 클릭 → 모달 → "선물 열기" → 광고 → 보상
5. 메인 복귀 → **빙수 만들기** 클릭 → 빙수 등장 → 얼음 갈기 시작
6. 광고 1번 → 진행도 1/5 → "얼음 더 갈기" 다시 누름
7. 5번 반복 → 토핑 단계 → 5번 반복 → 완성
8. 보상 받기 → 다음 빙수? 거기서 종료 (1개만 만들 예정)

**⚠️ 점검 포인트**
- IntroModal 한 번만 뜨는지 (재진입 시 안 떠야 함)
- 글자 크기 (62세 가독성). 메인 버튼 fontSize 22, OK
- 광고 응답 30초 timeout 후 에러 모달 — 사용자 당황 안 하게 안내 메시지 명확한가
- "받기" 버튼 누르면 즉시 메인 복귀? 빠르게 깜박이면 혼란

## 시나리오 B — 김민호 (32세) 매일 10/10 마감

1. 매일 같은 시간 진입 → 출석 선물 → 빙수 1개 → 다음 → 2개 → ... → 10개
2. 빙수 등장 → 얼음 5번 → 토핑 5번 → 완성 → "다음 빙수 만들기" → 반복
3. 10개째 완성 시 "오늘 영업 마무리" → daily-complete 화면

**⚠️ 점검 포인트**
- **10/10 시점 처리**: cheering 화면에서 "다음 빙수" → 11번째 시도? daily-complete로 가나?
- 코드: `if (state.todayBingsuCount + 1 >= MAX_BINGSU) → /daily-complete`. 10번째 만들 후 카운트 +1 = 10 → MAX_BINGSU(10) 도달 → daily-complete OK
- daily-complete 화면에서 "다시" 또는 메인으로 가는 버튼 명확한가
- 다음 날 자정(KST) 지나면 자동 리셋되는지 (앱 재진입 시점에)
- 메인 화면에서 0/10 표시 + 빙수 만들기 버튼 vs "오늘 영업 완료" 분기 정확한지

## 시나리오 C — 이수진 (24세) 첫 사용 + 빠른 이탈

1. 진입 → IntroModal → 어색하면 즉시 닫기
2. 메인 화면 → "출석 선물"·"빙수 만들기" 둘 다 보임 → 헷갈림
3. 빙수 만들기 클릭 → 광고 → 진행도 보이지만 5번 더 눌러야 함을 깨달음
4. 광고 1~2번 보고 흥미 잃음 → 앱 닫음

**⚠️ 점검 포인트**
- 진행 중 상태(currentStage='crushing', currentStageStep=2)에서 앱 닫고 재진입 시 → 메인? 진행중 화면? 코드 확인 필요
- "5번을 다 채워야 한다"는 시각적 안내 명확한가 (StepBar 있음 OK)
- 첫 광고 너무 빨리 나오면 → 거부감. 사용자가 마음의 준비할 시간

## 시나리오 D — 최진우 (45세) 광고 실패 케이스

1. 진입 → 출석 선물 클릭 → "선물 열기" → 광고 표시 시도
2. **광고 응답 없음** → 30초 timeout → 에러 모달
3. "다시 시도"? 또는 다른 앱으로 이탈?

**⚠️ 점검 포인트**
- 에러 모달의 메시지가 명확한가 ("광고 불러올 수 없어요" — OK)
- 재시도 버튼이 있는가 — 코드 확인: DailyGiftModal의 phase='error'에서 "닫기"만 있음 ⚠️ "다시 시도" 추가 필요?
- 광고 실패 시 출석 선물 카운트가 잘못 차감되거나 보상 미지급되는지
