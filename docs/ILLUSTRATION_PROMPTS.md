## STEP 1 — 팥빙수 베이스 (1회)

ChatGPT에 그대로 복붙:

```
빙수 가게 미니앱 캐릭터 디자인입니다.

🍧 팥빙수 캐릭터:
- 3등신 SD(chibi) 비율의 귀여운 빙수 그릇 캐릭터
- 통통하고 둥근 흰 도자기 그릇 형태
- 매우 큰 동그란 눈 (반짝이는 기대감)
- 빨간 팥, 하얀 얼음, 초록 떡 장식
- 빨간 팥 시럽

표정: 빈 그릇 상태, 기대하는 반짝이는 눈빛

스타일:
- Sanrio + Studio Ghibli 혼합
- Flat design + 부드러운 그림자
- 스티커 디자인
- 흰 배경
- 따뜻한 여름 파스텔 톤

정사각형 1:1, 고해상도
```

→ 결과 마음에 들 때까지 재생성. **이게 모든 빙수의 레퍼런스가 됨.**

## STEP 2 — 팥빙수 4상태 (1회)

Step 1 결과 이미지를 첨부하고 복붙:

```
위에 만든 팥빙수 캐릭터로 4가지 상태를 한 이미지에 2×2 그리드로 만들어주세요.
동일한 스타일, 비율, 색상을 정확히 유지하세요.

1. [빈 그릇] 텅 빈 흰 그릇 - 기대하는 반짝이는 눈빛
2. [얼음 가득] 하얀 얼음이 소복하게 쌓인 상태 - 설레는 표정 (살짝 미소)
3. [토핑 중] 빨간 팥과 초록 떡이 올라가는 중 - 행복한 표정 (만족스러운 웃음)
4. [완성 환호] 완성된 팥빙수, 점프하며 양옆으로 빛 발산 - 환호하는 표정

각각 흰 배경, 정사각형 1:1
```

→ 그리드를 받으면 **각 칸을 잘라서 저장**:

## 🖼️ Gemini 보조 (배경 + 소품) — 선택 사항

배경/소품은 ChatGPT보다 Gemini Imagen이 더 좋을 수 있음.

### 빙수 가게 배경

```
빙수 가게 배경 일러스트:
- 여름 느낌의 밝고 시원한 가게 인테리어
- 파스텔 하늘색(#00C4FF) + 흰색 톤
- 나무 선반에 빙수 그릇들이 진열
- 창문으로 들어오는 따뜻한 여름 햇살
- 천장에 작은 종 모빌
- Flat 일러스트 스타일
- 16:9 가로 비율
```

→ `src/assets/backgrounds/shop.png`

### 얼음 입자

```
반투명 파란빛 얼음 조각 PNG (배경 투명):
- 다양한 크기 6~8개
- 각각 다른 모양 (육각형, 둥근, 깨진 조각)
- 흰색-하늘색 그라데이션
- 빛 반사 효과
- 개별 PNG로 분리 가능하게
```

→ `src/assets/effects/ice/ice-1.png ~ ice-8.png`

### 시럽 방울

```
시럽 방울 PNG (배경 투명):
- 다양한 색상: 빨강, 노랑, 분홍, 보라, 초록, 황금
- 각 색상당 3개 크기 (작/중/대)
- 반짝이는 방울 형태
- 위쪽 하이라이트
```

→ `src/assets/effects/syrup/`

## 📌 작업 팁

1. **Step 1 베이스 팥빙수에 시간 투자**: 이게 모든 빙수의 기준이 됨. 마음에 들 때까지 재생성.
2. **complete.png는 항상 첨부**: 일관성 유지를 위해 매번 팥빙수 complete를 레퍼런스로 첨부.
3. **2×2 그리드 안 되면 4번 따로 요청**: 한 번에 4개 안 만들어주면 1, 2, 3, 4번 각각 따로.
4. **흰 배경 강조**: "투명 배경" 또는 "흰 배경"이 명확해야 잘라 쓰기 편함.
5. **이미지 크기**: 모두 정사각형 1024×1024 권장 (앱에서 리사이즈 처리).
6. **파일명은 영문 소문자**: `empty.png`, `ice.png`, `topping.png`, `complete.png` 정확히.
7. **잘라낸 후 PNG 저장**: 그리드 받으면 Photopea, GIMP, Photoshop 등으로 4분할 잘라서 저장.
