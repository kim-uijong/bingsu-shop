# DESIGN_SPEC.md — 오늘의 빙수 가게

## 디자인 컨셉

- **테마**: 여름 추억 빙수 가게
- **타겟**: 5060 (팥빙수 향수, 단순한 UI)
- **톤**: 따뜻함, 향수, 시원함
- **색상 주조**: 하늘색 계열 (#00C4FF) + 흰색 + 파스텔

## 화면 목록 (8종)

| 화면 | 파일 | 설명 |
|------|------|------|
| 인트로 | `Intro.tsx` | 앱 로딩 + 첫 진입 |
| 메인 | `Main.tsx` | 빙수 가게 입구, 출석 선물, 0/10 카운터 |

## 컴포넌트 스펙

### StepBar (진행도)
```
STAGE 1: 얼음 갈기  ▓▓▓░░ 3/5
STAGE 2: 토핑 올리기 ░░░░░ 0/5
```
- 두 스테이지 모두 표시
- 현재 스테이지 강조

### DailyCounter (일일 카운터)
```
오늘 빙수: 🍧🍧🍧░░░░░░░  3/10
```
- 완성된 빙수는 아이콘으로 표시

### BannerAd (하단 고정)
- 모든 화면 하단에 배너 광고 고정
- 높이 50dp

## 5060 타겟 UI 원칙

1. **폰트 크기**: 본문 최소 16sp, 제목 24sp 이상
2. **버튼 크기**: 최소 48dp 높이
3. **대비**: 텍스트-배경 대비율 높게
4. **단순함**: 한 화면에 버튼 최대 2개
5. **명확한 진행**: 현재 단계 항상 표시
