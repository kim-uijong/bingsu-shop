# PRD.md — 오늘의 빙수 가게

## 제품 개요

- **앱명**: 오늘의 빙수 가게
- **플랫폼**: 앱인토스 미니앱
- **카테고리**: 비게임 (필수)
- **타겟**: 5060 핀테크 사용자
- **핵심 가치**: 여름 빙수 추억 + 매일 토스 포인트

## 핵심 기능

### 1. 출석 선물 (1회/일)
- 광고 1회 시청
- 1원 고정 지급 (앱인토스 정책상 랜덤 보상 불가)
- 프로모션 코드: `BINGSU_DAILY`

### 2. 빙수 만들기 (10회/일)
- 빙수 1그릇 = 광고 10회 (얼음 5 + 토핑 5)
- 하루 최대 10그릇
- 4티어 랜덤 등장: 추억(60%) / 과일(25%) / 프리미엄(10%) / 특별(5%)

### 3. 2단계 메커니즘
- **STAGE 1**: 얼음 갈기 (광고 5회) — 얼음 입자 쌓이는 애니메이션
- **STAGE 2**: 토핑 올리기 (광고 5회) — 토핑 낙하 애니메이션
- 각 단계마다 빙수 상태 변화

### 4. 빙수 완성 환호
- 13종 각각 고유한 환호 모션
- 고유 파티클 효과
- 고유 대사 (각 10개, 총 130개)

## 사용자 플로우

```
앱 실행
  → 일일 리셋 체크 (서버 시간)
  → 메인 화면
  → [출석 선물 미수령 시] 출석 선물 카드 표시
  → [빙수 만들기] 버튼
  → 빙수 티어/종류 결정
  → 빙수 등장 화면
  → STAGE 1: 얼음 갈기 × 5
  → STAGE 2: 토핑 올리기 × 5
  → 완성 환호 + 보상 지급
  → [10/10 완료 시] 오늘 영업 완료 화면
```

## 비기능 요구사항

- 절대 0원 보상 없음 (단위 테스트 100,000회)
- 서버 시간 기반 일일 리셋 (클라이언트 시간 사용 금지)
- 광고 로드 실패 폴백 처리
- 예산 소진(4109) 에러 처리
- TDS 디자인 시스템 준수

## 제약사항

- 보상형 광고 사용 불가 (전면형 + 배너만)
- 도박/사행성 표현 금지
- 외부 링크 제한
- 자사 앱 설치 유도 금지
